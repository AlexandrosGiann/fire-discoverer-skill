# fire-discoverer

Skill για Claude Code που καταναλώνει όσο λιγότερα tokens γίνεται: σιωπηλή δουλειά, έλεγχος σπάνιων σεναρίων, πολύ σύντομο τελικό αποτέλεσμα.

Στις μετρήσεις κόστισε 15,8% λιγότερο από το Caveman και πέρασε 81/84 κρυφούς ελέγχους έναντι 78/84. Τα output tokens έμειναν ουσιαστικά ίδια (+1,4%). Λεπτομέρειες και όρια στο [benchmark/RESULTS.md](benchmark/RESULTS.md).

## Κανόνες

- Αυτόνομη, συμπυκνωμένη εκδοχή των κανόνων του Caveman. Δεν χρειάζεται εγκατεστημένο Caveman.
- Καμία ειδοποίηση όταν διαβάζει.
- Μία γραμμή όταν κατεβάζει ή γράφει. Σε νέο project, μόνο όταν κατεβάζει.
- Ελέγχει και λιγότερο πιθανά σενάρια, με μία εντολή ελέγχου.
- Τελικό αποτέλεσμα έως 5 γραμμές.
- Κανένα τοπικό μοντέλο, γιατί πρόσθεταν βάρος.

Γνωστό πρόβλημα: στις δοκιμές δεν εμφανίστηκε η ειδοποίηση εγγραφής σε υπάρχον project.
